# 福州大学主页（示例）

文件说明：
- 规划单：规划单.md
- 主页文件：index.html
- 样式：style.css
- 脚本（留言板）：script.js

如何使用：
1. 在文件夹中打开 `index.html`（直接在浏览器中打开即可）。
2. 若想替换横幅图片，请把图片放到 `images/campus.jpg`，或修改 `index.html` 中的图片路径。

作业要求提醒：
- 请在白纸上绘制页面线框图（wireframe）。
- 在 `script.js` 中已经用中文注释解释了 `document.getElementById` 和 `addEventListener` 等关键 API，请基于这些注释写一段你自己的代码解读文本并粘贴到作业提交处。
